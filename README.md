# Phytochemical and Antioxidant Activity Analysis

## Project Overview
This project focuses on analysing the antioxidant activity of medicinal plant extracts using Python programming.

## Objectives
- Calculate percentage inhibition.
- Analyse DPPH antioxidant activity.
- Estimate IC50 values.
- Generate dose-response curves.
- Visualise experimental data.

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- SciPy

## Pharmaceutical Applications
This project demonstrates how programming and data analysis can be applied to pharmacological and phytochemical research.

## Project Status
Beginner-level educational project – Work in Progress.
